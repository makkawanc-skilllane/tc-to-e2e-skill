# บั๊กและคำถาม BA

## จัดประเภทก่อน

| ประเภท | ใช้เมื่อ | ทำอะไร |
|---|---|---|
| บั๊ก | ระบบทำต่างจากตั๋ว (AC) ทั้งที่ฟีเจอร์ลงแล้ว | สร้างไฟล์บั๊ก |
| ยังไม่พัฒนา | ยังไม่มีฟีเจอร์ในโค้ด | `test.fixme` + plan `Blocked` |
| ต้องถาม BA | Figma ↔ ตั๋วไม่ตรงกัน, ตั๋วไม่ชัด, หรือโค้ดตรงกับ Figma แต่ไม่ตรงกับตั๋ว | ตั้งคำถามพร้อมลิงก์ frame |
| แก้ TC | ชีตเขียนผิด แต่ทุกแหล่งตรงกัน | เสนอข้อความใหม่ให้ผู้ใช้ |

## ไฟล์บั๊ก

เก็บตามที่ `TC_TO_E2E.md` กำหนด เลขไฟล์ต่อจากเลขล่าสุดในโฟลเดอร์ และอัปเดตตาราง TC → บั๊ก ใน README ของโฟลเดอร์นั้น

```markdown
# BUG-12 <ชื่อสั้น บอกอาการ>

| | |
|---|---|
| หน้า/ส่วน | … |
| TC | TC-HOME-014 |
| Env | staging · app.example.com |
| พบเมื่อ | 2026-10-28 |
| ตั๋ว | PROJ-183 |

## ขั้นตอน
1. …

## Expected (อ้าง AC ข้อ … ของตั๋ว)
…

## Actual
…

![crop](BUG-12-crop.png)
[ภาพเต็ม](BUG-12.png)

## หมายเหตุ
โค้ดต้นเหตุ: `src/…/Widget.tsx:88` …
```

- บั๊กที่เกี่ยวกับหน้าตา: ใส่ลิงก์ Figma frame และวางภาพ Figma คู่กับภาพจริงจาก env
- ไฟล์แนบในระบบตั๋ว ส่วนใหญ่แนบผ่าน MCP ไม่ได้ ให้บอกผู้ใช้ว่าต้องแนบภาพเอง

## ภาพ crop สำหรับ dev

dev ต้องอ่านจบได้ในภาพเดียว:
- ครอปเฉพาะส่วนที่ผิด ตีกรอบแดงพร้อมเลข 1, 2, 3
- เขียนป้ายในภาพทีละข้อเป็น `ที่แสดง ➜ ควรเป็น …` ถ้าส่วนนั้นขาดไป ให้เขียน `ไม่มี …`

```sh
node ~/.claude/skills/tc-to-e2e/scripts/annotate-bug-image.mjs bugs/BUG-12.json
```

`BUG-12.json` (พิกัดอ้างอิงภาพต้นฉบับ ตัวอย่างอยู่ที่ `examples/annotate.example.json`):

```json
{
  "src": "BUG-12.png",
  "out": "BUG-12-crop.png",
  "crop": [460, 80, 860, 480],
  "boxes": [{ "rect": [505, 196, 115, 36], "n": 1 }],
  "notes": [{ "n": 1, "text": "chip \"ปิดภาคเรียน\" ➜ ควรเป็น \"ปิดภาคเรียนแล้ว\"" }],
  "notesAt": [516, 330],
  "question": "ไม่บังคับ: แถบคำถามสีน้ำเงินเหนือภาพ"
}
```

- **ห้ามใช้ PIL เขียนข้อความไทย** เพราะสระและวรรณยุกต์จะกลายเป็นกล่อง สคริปต์นี้ render ผ่าน Chromium จึงไม่มีปัญหานี้
- เปิดดูภาพที่ได้ทุกครั้ง

## คำถาม BA

- ส่งไปที่และใช้ถ้อยคำตามที่ `TC_TO_E2E.md` กำหนด (บางทีมมีคำที่ห้ามใช้เรียกผู้รับ)
- 1 คำถาม = 1 แถว: TC, สิ่งที่ไม่ตรงกัน (ชีต / ตั๋ว / Figma / โค้ด), ลิงก์ frame, ข้อเสนอ
- อ้างเลขคำถามไว้ใน `test.fixme` และใน `reason` ของเคส
